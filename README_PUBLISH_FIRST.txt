PUBLISH ON GITHUB PAGES
1. Sign in to https://github.com
2. Create a PUBLIC repository named 'portfolio' (or another name you prefer).
3. Upload index.html and Jovanie_Mazon_Resume.docx from this folder to the ROOT of the repository. Do not upload confidential work data.
4. Open repository Settings > Pages.
5. Under Build and deployment choose Source: Deploy from a branch. Choose branch main and folder /(root); Save.
6. Once GitHub finishes deploying, your URL will generally be https://YOUR-GITHUB-USERNAME.github.io/portfolio/ (if repository is named portfolio).
7. Verify the URL in your browser, then paste the ACTUAL URL into LinkedIn's Featured section and the [LinkedIn or Portfolio URL] field on job applications.
